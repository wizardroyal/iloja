ILOJA — UI Screen Reference Files
==================================

7 screens exported as standalone HTML files.
Open any file in Chrome or Safari to view.
All screens are mobile-width (390px) centered on a desktop background.

Files:
  01-home.html              — Renter home / discovery screen
  02-property-detail.html   — Property listing page with escrow CTA
  03-agent-profile.html     — Agent credibility profile
  04-escrow-booking.html    — Inspection scheduling + escrow flow (3 steps, interactive)
  05-chat-offer.html        — In-app chat with offer/counter-offer flow (interactive)
  06-agent-dashboard.html   — Agent CRM dashboard
  07-listing-creation.html  — Agent listing creation flow (4 steps, interactive)

Design system:
  Fonts:   Fraunces (display/prices) + DM Sans (body)
  Primary: #1A3C34 (Forest) / #2D6A4F (Grove)
  BG:      #F7F4EE (Cream) / #EDE9E0 (Parchment)
  Chain:   Base L2 — document hashes only at launch

All screens load Google Fonts from CDN — requires internet connection.
